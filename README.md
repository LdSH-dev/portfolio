# leonardo hemming — portfolio

Personal portfolio of Leonardo Hemming, Senior Full-Stack Engineer (React · Node.js · TypeScript).

- **Ask my digital twin**: a chat grounded only in my real career data (`src/content/profile.ts`), streamed from Claude Haiku 4.5.
- **Live PageSpeed test**: visitors run Google's PageSpeed Insights audit on the site itself.
- **Book a call**: Google Calendar appointment schedule in a modal.
- Canvas-rendered orthographic globe, custom cursor, motion-driven reveals, GitHub contribution heatmap.

Built with Next.js 16 (App Router, Cache Components), React 19, Tailwind CSS 4 and Motion. Deployed on Vercel.

## Running locally

```bash
cp .env.example .env.local   # fill in the values
npm install
npm run dev
```
